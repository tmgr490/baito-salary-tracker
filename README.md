# 給与ノート

バイトのシフトから給与と「年収の壁」を管理するツールです。
HTMLファイル1つで動き、サーバーもアカウントも必要ありません。

**▶ https://tmgr490.github.io/baito-salary-tracker/**

---

## できること

- **給与明細(PDF)の取り込み** — Web明細やメール添付のPDFから支給額・通勤手当を自動で読み取り。
  パスワード付きPDFや複数ヶ月分が1つになったPDFにも対応。読み取った値は確認・修正してから登録
- **シフト入力** — 勤務日と時刻を入れるだけ。時間帯別の時給、日祝加算、休憩の控除を自動計算
- **シフトのカレンダー** — 登録済みのシフトを日曜始まりのカレンダーで表示。日付をタップするとその日の内訳と削除ボタンが出る（表形式にも切り替え可）
- **有給休暇** — 取得日と時間数を記録。賃金の計算方法（基本時給／時間帯別の時給／平均賃金／固定額）を
  バイト先ごとに設定でき、実際に出勤していないので通勤費は既定で付けません
- **給与サイクル** — 締め日・支払日の設定にあわせて、支給額と振込日を算出。実際の振込額とズレたら訂正入力で上書きできる
- **年収の壁** — 住民税・所得税・扶養控除・社会保険の扶養などを、年齢や扶養の状況に応じて自動で出し分け。年末の着地予想も表示
- **週20時間の判定** — 勤務先ごとに月ごとの週平均労働時間を並べ、社会保険の加入基準（2ヶ月連続で週20時間、4分の3基準）を監視。企業規模要件の段階的な引き下げにも追随
- **判定の確からしさ** — その判定に効く項目がどれだけ埋まっているかを割合で表示し、未入力の項目が結論をどう変えうるかを明示（判定が当たる確率ではありません）
- **超過時の対応** — 壁に近づいた／超えた時にやることをチェックリストで表示
- **複数のバイト先** — 掛け持ちしていても合算して壁を判定
- **通勤費** — 往復運賃と定期券代を勤務日数で自動的に切り替え。非課税分は壁の判定から除外

## データの扱い

**入力したデータは、あなたの端末のブラウザの中（localStorage）だけに保存されます。**
サーバーには一切送信されません。作者を含め、誰も見ることはできません。
このページは公開URLにありますが、他の人が開いても見えるのは空のアプリだけです。

覚えておいてください:

- ブラウザの閲覧データを削除すると、入力内容も一緒に消えます
- スマホとパソコンでデータは共有されません（設定タブの書き出し・読み込みで移せます）
- **iPhone / iPad の Safari は、7日間そのサイトを開かないと保存データを自動削除します**
  （iOS 13.4 以降の仕様）。ホーム画面に追加して使うとこの削除の対象外になります
- 外部に接続するのは「祝日の自動取得」（holidays-jp.github.io）だけです。この時もあなたのデータは送信しません
- **PDFの給与明細もこの端末の中だけで解析します。** 解析に使う pdf.js は
  CDNから読まずにリポジトリに同梱してあるため、PDFを扱っても外部への通信は発生しません

こまめにバックアップを書き出しておくことを強くおすすめします。
未書き出しの変更が7日以上あると、ホーム画面で書き出しを促します。

### スマホで使う場合（推奨）

**ホーム画面に追加してください。** 見た目の問題ではなく、上に書いた
iOS の7日ルールを回避するためです。

- iPhone / iPad … Safari で開き、共有ボタン → 「ホーム画面に追加」
- Android … Chrome のメニュー → 「アプリをインストール」

追加するとオフラインでも開けるようになります。

### 端末間でデータを移す

設定タブの「端末間でデータを移す」から書き出し、もう片方の端末で読み込みます。
読み込む時に **「上書き」か「追加（マージ）」を選べる**ので、両方の端末で
別々に入力していても消えません。同じ勤務が二重に増えることもありません
（日付・時刻・勤務先で重複を判定します）。ただしプロフィールや端数処理などの設定は、
「追加」では手元の内容をそのまま残します。

## 税制データについて

最終確認: **2026-09-16**

令和8年度税制改正（令和8年12月1日施行・令和8年分以後の所得税に適用）に対応しています。

| 壁 | 令和8年分 | 内訳 |
|---|---|---|
| 住民税（均等割） | 119万円 ※1級地 | 非課税限度額45万 ＋ 給与所得控除74万 |
| 住民税（所得割） | 119万円 | 非課税限度額45万（全国共通）＋ 給与所得控除74万 |
| 勤労学生控除 | 163万円 | 合計所得89万 ＋ 給与所得控除74万 |
| 扶養控除 | 136万円 | 扶養親族の合計所得要件62万 ＋ 給与所得控除74万 |
| 特定親族特別控除 | 159万円（満額）／197万円（ゼロ） | 合計所得85万／123万 |
| 配偶者特別控除 | 169万円（満額）／207万円（ゼロ） | 合計所得95万／133万 |
| 所得税 | 178万円 | 給与所得控除74万 ＋ 基礎控除104万 |
| 社会保険の扶養 | 130万円（19〜22歳は150万円） | 2025年10月1日以降の認定分 |

年齢は**生まれた年**から「その年の12月31日時点」で計算します。扶養控除・特定扶養控除・
老人扶養控除はこの時点の年齢で決まるため、対象年を切り替えても判定がずれません。

| 年齢（12/31時点） | 扱い |
|---|---|
| 16歳未満 | 年少扶養親族。**扶養控除そのものが無い**ので、その壁は表示しません |
| 18歳未満（翌1/1時点） | **住民税は合計所得135万円（給与209万円）まで全額非課税** |
| 19〜22歳 | 特定扶養控除・特定親族特別控除／社会保険の扶養150万円（配偶者を除く） |
| 23〜69歳 | 一般の扶養控除（38万円） |
| 70歳以上 | 老人扶養控除（48万円）。同居老親等なら58万円（設定タブで選べます） |

障害者控除・ひとり親控除・寡婦控除は設定タブで選べます。所得税の壁が27万〜75万円うしろにずれ、
住民税も合計所得135万円まで非課税になります。手帳の等級と税法上の「一般／特別」の対応は
設定タブのガイドに載せてあります。

配偶者控除・配偶者特別控除は、**扶養している方の合計所得**で控除額が変わります。

| 扶養している方の合計所得 | 配偶者控除 | 老人控除対象配偶者 | 配偶者特別控除(満額) |
|---|---|---|---|
| 900万円以下 | 38万円 | 48万円 | 38万円 |
| 900万円超 950万円以下 | 26万円 | 32万円 | 26万円 |
| 950万円超 1,000万円以下 | 13万円 | 16万円 | 13万円 |
| 1,000万円超 | 適用なし | 適用なし | 適用なし |

1,000万円超を選ぶと、失うものが無いので配偶者控除の壁自体を表示しません
（社会保険の扶養と自分にかかる税金は残ります）。扶養控除・特定親族特別控除には
この所得制限はありません。

住民税の均等割は級地区分で変わります（設定タブで選べます）。

| 級地 | 非課税限度額 | 給与収入 |
|---|---|---|
| 1級地（東京23区・政令指定都市など） | 45万円 | 119万円 |
| 2級地（中規模の市） | 41.5万円 | 115.5万円 |
| 3級地（町村部など） | 38万円 | 112万円 |

社会保険の扶養は**年収だけでは決まりません**。健保組合は直近3ヶ月の平均月収で見ることが多く、
2026年4月からは労働契約の内容から年収を見積もる方式も加わりました。
アプリでは月額基準（130万→108,333円／150万→125,000円）と週の平均労働時間も表示します。

注意すべき点:

- **178万円・136万円などは令和8年分・令和9年分限りの時限措置**です。令和10年分以降は
  物価に応じて再設定される見込みなので、そのタイミングで数値の見直しが必要になります
- **社会保険加入の賃金要件（月8.8万円＝年106万円）は 2026年10月1日に廃止**されました。
  以後は「週の所定労働時間20時間以上」などが判定の中心になります
- 住民税の非課税限度額は**扶養親族がいない単身者**の金額です。扶養している家族がいる場合は上がります
- **家族手当・扶養手当**は会社ごとの制度なので壁には含まれていません。基準額（多くは103万や130万）を
  超えると手当が無くなることがあり、税金より影響が大きい場合もあります
- 住民税の非課税限度額は**扶養親族がいない単身者**の金額です（このアプリを使う本人に扶養親族がいる場合は上がります）
- 相続税の障害者控除、医療費控除、社会保険料控除など、**バイト収入の「壁」に直接関係しない控除**は扱っていません

### 有給休暇の賃金

労基法39条は3通りの出し方を認めていて、どれを使うかは勤務先の**就業規則**で決まっています。

| 設定 | 計算 |
|---|---|
| 基本時給 × 時間 | 「通常の賃金」。時給制でいちばん多い |
| 時間帯別の時給 × 時間 | 深夜帯など時給が変わる時間に入っていた場合 |
| 平均賃金（直近3ヶ月） | 労基法12条。賃金総額 ÷ 暦日数。時給制は「労働日数で割って60%」の最低保障があるので高いほうを使います |
| 1日あたり固定額 | 労使協定による標準報酬日額など、明細が定額のとき |

有給の賃金も給与収入なので「年収の壁」に含めます。週20時間の判定にも時間数を含めています
（有給を取った日はもともと所定労働日なので、実態に近いため）。

## 免責

このアプリの計算結果はあくまで目安です。制度は改正されることがあり、個別の事情によって
扱いも変わります。実際の判断は、勤務先の担当者・お住まいの自治体・国税庁・日本年金機構の
公式情報でご確認ください。

## 技術的なこと

- アプリ本体は単一のHTMLファイル。ビルド不要
- PDF解析にのみ pdf.js（`vendor/`、Apache-2.0）を使用。約1.8MBあるため、
  利用者がPDF取り込みを開いた時にだけ読み込まれます
- **`.nojekyll` は消さないでください。** Jekyll は `vendor/` を既定で除外するため、
  これが無いとPDF取り込みだけが動かなくなります
- 保存先は localStorage。PCのChrome/Edgeでは File System Access API で
  任意のファイルに同期することもできます（設定タブ）
- ライト／ダークテーマ対応
